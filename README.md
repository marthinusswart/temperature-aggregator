# Temperature Aggregator API

The Temperature Aggregator API is a lightweight microservice built with FastAPI that ingests, stores, and serves temperature readings from various components or sensors. It uses an in-memory data structure to manage incoming data and provides endpoints to query aggregated statistics.

## Features

- **Data Ingestion:** Accepts temperature readings from sensors (`componentId`, `temperature`, `timestamp`). If no timestamp is provided, it defaults to the current server epoch time.
- **Data Aggregation:** Retrieves all readings, groups readings by component, or fetches readings for specific components.
- **Latest Readings:** Efficiently fetches the most recent temperature reading for any given component using timestamp evaluation.
- **In-Memory Storage:** Utilizes a fast, volatile in-memory data store for demonstration and rapid read/write operations.

## Tech Stack

- **Python 3**
- **FastAPI:** High-performance ASGI web framework.
- **Pydantic:** Data validation and type enforcement.
- **Uvicorn:** ASGI web server.
- **Pytest & HTTPX:** Test client and framework for unit testing API endpoints.

## API Endpoints (`/api/v1`)

- `GET /is-alive`: Health check to verify the service status.
- `POST /temperature-reading`: Submit a new temperature reading.
- `GET /temperature-readings`: Retrieve all stored temperature readings, grouped by `componentId`.
- `GET /temperature-readings/{component_id}`: Retrieve all readings for a specific component.
- `GET /temperature-readings/{component_id}/latest`: Retrieve the most recent temperature reading for a specific component.
- `GET /docs`: Interactive Swagger UI documentation (auto-generated by FastAPI at the root level).

## Running the Application

To run the application locally, execute the app module as a script:

```bash
python -m app.main
```

## Running Tests

To run the automated tests, navigate to the project root and install the testing dependencies if you haven't already:

```bash
pip install pytest httpx
```

Then, execute the test runner:

```bash
pytest
```
